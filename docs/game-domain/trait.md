# 특성 (Trait)

## 특성 시스템 개요

각 직원은 고유한 특성을 보유하며, 이 특성이 업무 성과와 팀 역학에 중대한 영향을 미친다.

- 각 직원은 **정확히 3개** 특성을 보유한다: **업무 스타일 1개 + 사회성 1개 + 랜덤(아무 카테고리) 1개**
- 특성은 채용 후 **구조적 공개 시스템**을 통해 점진적으로 드러난다 (아래 참조).

---

## 특성 공개 시스템

특성은 완전한 랜덤이 아닌, **구조화된 단계**를 통해 공개된다. 플레이어는 이력서의 힌트를 분석하여 채용 리스크를 판단할 수 있다.

### 공개 단계

| 단계 | 시점 | 공개 수준 |
|------|------|----------|
| **이력서** | 채용 전 | 특성 1~2개 **확실 공개** + 나머지는 **힌트 텍스트** |
| **수습 4턴** | 입사 후 1개월 | 비공개 특성의 **카테고리 힌트** 공개 |
| **수습 8턴** | 입사 후 2개월 | 비공개 특성의 **구체적 힌트** 공개 |
| **수습 12턴** | 전환 결정 전 | 모든 특성 **완전 공개** |

### 힌트 예시

| 공개 수준 | 표시 예시 |
|----------|----------|
| 확실 공개 | ✅ 완벽주의자 — 코드품질 +3, 작업 완료까지 +1턴 |
| 카테고리 힌트 (4턴) | 💬 "리스크 계열 특성으로 보인다" |
| 구체적 힌트 (8턴) | 💬 "다른 회사에 관심이 있는 것 같다" (→ 이직욕구자 추정) |
| 완전 공개 (12턴) | ✅ 이직욕구자 — 충성도 기본 -2, 경쟁사 접촉 확률 상승 |

### 고용 형태별 차이

| 고용 형태 | 공개 방식 |
|----------|----------|
| **정규직** | 위 단계대로 12턴에 걸쳐 공개 (수습 전환 전 모두 공개) |
| **계약직** | 수습 기간 없음. 근무 시작 후 **8턴 이내** 전체 공개 |
| **외주 사원** | 수습 기간 없음. 근무 시작 후 **8턴 이내** 전체 공개 |

## 업무 스타일 특성 (7종)

| 특성명 | 영문 키 | 효과 |
|--------|---------|------|
| 스프린터 | `Sprinter` | 단기 집중력 상승, 장기 프로젝트 후반부 생산성 하락 |
| 마라토너 | `Marathoner` | 초반 느리지만 후반에 꾸준히 고효율 유지 |
| 야근장인 | `OvertimeMaster` | 야근 시 생산성 페널티 없음, 체력 소모 2배 |
| 워라밸사수 | `WorkLifeBalance` | 야근 거부, 정시 퇴근 보장 시 충성도 +2/턴 |
| 속도제일주의 | `SpeedFirst` | 구현속도 +2, 버그 확률 +10% |
| 완벽주의자 | `Perfectionist` | 코드품질 +3, 작업 완료까지 +1턴 소요 |
| 데드라인기적러 | `DeadlineMiracle` | 마감 2턴 전까지 60% 효율, 마감턴에 150% 효율 |

## 사회성 특성 (7종)

| 특성명 | 영문 키 | 효과 |
|--------|---------|------|
| 레크레이션장인 | `RecreationMaster` | 팀 이벤트 시 케미 +10%, 집중 업무 시 -5% |
| 점심혼밥파 | `SoloLuncher` | 개인 멘탈 안정, 케미 기여도 낮음 |
| 번개주도자 | `GatheringInitiator` | 비공식 모임 제안, 케미 랜덤 변화 |
| 험담꾼 | `Gossiper` | 특정 팀원 케미 -3, 발각 시 명성 -10 |
| 배려형리더 | `CaringLeader` | 주변 팀원 멘탈 회복 +1/턴, 자신 생산성 -5% |
| 냉소주의자 | `Cynic` | 업무 능력 우수, 신입 온보딩 효율 -20% |
| 리더병 | `LeaderComplex` | 팀장 아닐 때: 팀 케미 -2/턴. 팀장일 때: 팀원 성장속도 -1. "아래 업무" 거부 |

## 성장 특성 (5종)

| 특성명 | 영문 키 | 효과 |
|--------|---------|------|
| 독학왕 | `SelfLearner` | 성장속도 +3, 외부 교육비 효과 2배 |

| 천장이낮음 | `LowCeiling` | 초반 성장 빠르나 스탯 상한이 낮음 |
| 잠재력덩어리 | `HiddenPotential` | 초기 스탯 낮지만 급성장 가능 |
| 컨퍼런스중독자 | `ConferenceAddict` | 8턴마다 컨퍼런스 참석 요청. 거부 시 충성도 -2. 승인 시 1턴 부재 + 이후 4턴 성장속도 +1, 명성 +1 |

## 리스크 특성 (4종)

| 특성명 | 영문 키 | 효과 |
|--------|---------|------|
| 이직욕구자 | `JobHopper` | 충성도 기본 -2, 경쟁사 접촉 확률 상승 |
| 창업꿈나무 | `StartupDreamer` | 재직 48턴 후 퇴사 및 기술유출 가능성 |
| 번아웃취약자 | `BurnoutProne` | 체력 0 이하 시 돌연 병가 발생 |
| 민감한자존심 | `SensitiveEgo` | 공개 피드백 시 불만 폭발, 1:1 피드백은 정상 수용 |

> **참고**: 리스크 특성의 임계값은 공통 스탯 -1~5 범위 기준이다. 예: 번아웃취약자의 발동 조건은 체력 0 이하.

## 특성 충돌/시너지 매트릭스

특성 조합에 따라 팀원 간 케미가 자동으로 보정된다. 아래 표에 명시되지 않은 조합은 **중립(0)**으로 처리된다.

### 충돌 조합 (개인 간 케미 감소)

| 특성 A | 특성 B | 효과 | 사유 |
|--------|--------|------|------|
| 완벽주의자 | 속도제일주의 | -8 | 품질 vs 속도 근본적 가치관 충돌 |
| 리더병 | 리더병 | -8 | 두 명의 자칭 리더, 끝없는 주도권 다툼 |
| 야근장인 | 워라밸사수 | -6 | 근무시간 가치관 정면충돌 |
| 험담꾼 | 민감한자존심 | -6 | 험담 대상이 될 경우 폭발 |
| 리더병 | 배려형리더 | -7 | 권위적 리더 vs 배려형 리더, 리더십 스타일 충돌 |
| 배려형리더 | 냉소주의자 | -5 | 온보딩/협업 스타일 충돌 |
| 험담꾼 | 배려형리더 | -5 | 험담꾼의 행동이 배려형에게 스트레스 |
| 완벽주의자 | 데드라인기적러 | -4 | 꾸준함 vs 몰아치기 충돌 |
| 컨퍼런스중독자 | 완벽주의자 | -4 | 컨퍼런스 부재가 업무 품질 저하 야기 |
| 스프린터 | 마라토너 | -3 | 작업 리듬 불일치 |
| 레크레이션장인 | 점심혼밥파 | -3 | 사교 스타일 차이 |
| 속도제일주의 | 마라토너 | -3 | 빠른 결과물 vs 느린 진행 |
| 이직욕구자 | 멘토체질 | -3 | 멘토의 투자가 무위로 돌아감 |
