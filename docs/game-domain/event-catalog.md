# 이벤트 카탈로그 (Event Catalog)

이 문서는 게임에서 발생하는 모든 이벤트의 목록이다. 이벤트의 메커니즘(발동 방식, 레이어 구분)은 [이벤트 시스템](../game-system/game-event.md)을 참조.

---

## 시장 트렌드 이벤트 (5종)

**발생 주기**: 매 20~30턴마다 1개

| 이벤트 | 발생 확률 | 지속 | 효과 |
|--------|----------|------|------|
| AI 기술 붐 | 15% | 12~20턴 | AI 서비스 MAU 전환율 2배, 개발자 채용 경쟁↑ |
| 경기 침체 | 10% | 20~30턴 | 외주 -40%, 투자 성공률 -20% |
| 개발자 대란 | 12% | 8~16턴 | 이직 빈도 2배, 연봉 협상↑ |
| 스타트업 투자 호황 | 10% | 12~16턴 | 투자 성공률 +20%, 규모 상한↑ |
| 플랫폼 정책 변화 | 8% | 영구 | 특정 마케팅 채널 효율 급변 |

## 법/규제 이벤트 (4종)

| 이벤트 | 발생 조건 | 선택지 | 결과 |
|--------|----------|--------|------|
| 개인정보 처리 감사 | 데이터 파트너십 보유 시↑ | 즉시 개선 / 무시 | 개선: 비용 / 무시: 과태료 |
| 근로기준법 위반 조사 | 야근문화 태그+8턴 연속 야근 | 자발적 시정 / 방어 | 시정: 비용+명성 보정 / 방어: 장기 소송 |
| 공정거래 조사 | 시장 점유율 60%+ | 협조 / 법적 대응 | 협조: 시간 / 대응: 명성 -20 |
| 개인정보 유출 사고 | 보안감각 낮음+트래픽 급등 | 즉시 공개 / 은폐 시도 | 공개: 명성 -15 / 은폐 발각: 명성 -40 |

## 랜덤 이벤트 테이블 (12종)

| 이벤트 | 발생 조건 | 선택지 | 결과 |
|--------|----------|--------|------|
| 핵심 개발자 이직 통보 | 충성도 3 이하 | 연봉 인상/붙잡지 않음 | 수락: 비용↑ / 거절: 생산성 급락 |
| 경쟁사 스카웃 오퍼 | 명성 높을수록 빈번 | 대응/방치 | 미대응 시 이탈 |
| 클라 요구사항 전면 수정 | 외주 진행 중 | 수용/거절 | 수용: 납기 지연 / 거절: 계약 파기 리스크 |
| 팀원 간 공개 갈등 | 케미 30 이하 | 중재/방관 | 중재 성공 시 회복 |
| 개발자 코드 날림 사고 | 보안감각 낮음 | 밤새 복구/납기 연장 | 복구: 체력↓ / 연장: 만족도↓ |
| 전 직원 명절 연휴 | 분기 1회 | 특별 보너스/일반 | 보너스: 충성도↑ |
| 스타트업 언론 인터뷰 | 명성 55+ | 수락/거절 | 수락: 명성↑, 대표 시간 소모 |
| 투자사 실사 방문 | 투자 진행 중 | 준비 충실/날림 | 준비도 → 투자 성공률 |
| 팀원 번아웃 선언 | 체력 2 이하 | 유급휴가/강행 | 강행: 퇴사↑ |
| 보안 취약점 발견 | 안정성 낮음 | 즉시 패치/모른척 | 모른척: 해킹 가능 |
| 신입 온보딩 실패 | 냉소주의자 존재 | 멘토 배정/방치 | 방치: 수습 생산성 60% 고착 |
| 근로기준법 위반 신고 | 야근문화+8턴 야근 | 자발적 시정/법적 대응 | 시정: 비용+명성+3 / 대응: 소송 |
