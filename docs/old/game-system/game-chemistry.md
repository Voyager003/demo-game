# 케미스트리 시스템 (Chemistry System)

## 1. 케미 수치 종류

| 수치 | 설명 | 범위 |
|------|------|------|
| 팀 전체 케미(TeamChemistry) | 회사 분위기 전반 | 0~100 |
| 개인 간 케미(IndividualChemistry) | 두 직원 사이 궁합 | -50~+50 |
| 팀 문화 성향(CultureTag) | 지배적 분위기 태그 | 태그 방식 |

---

## 2. 팀 전체 케미 계산

- **초기값**: 50 (보통)
- **변동 요인**: 복지비 효과, 팀 이벤트, 채용/해고, 프로젝트 성공/실패

### 구간별 효과

| 구간 | 효과 |
|------|------|
| 90~100 | 프로젝트 완료 -1턴, 투자 IR +10% |
| 70~89 | 표준 |
| 50~69 | 회의 증가, 생산성 -5% |
| 30~49 | 갈등 이벤트↑, 이직 시도 |
| 0~29 | 연쇄 이탈 위험, 프로젝트 중단 |

---

## 3. 개인 간 케미 연산

```
기본값: 0
특성 충돌: -3~-8 (trait.md 매트릭스 참조)
특성 시너지: +3~+10 (trait.md 매트릭스 참조)
같은 직군: -2 (경쟁 심리)
같은 출신: ±랜덤 (친밀감 or 경쟁)
함께 프로젝트 성공: +5
함께 프로젝트 실패: -5
```

### 공통 스탯의 케미 영향

직원의 공통 스탯(-1~5)이 낮을 경우 케미에 추가적인 부정 영향을 미친다.

| 공통 스탯 | 조건 | 케미 영향 |
|----------|------|----------|
| 커뮤니케이션 | -1 | 해당 직원과의 모든 개인 간 케미 -3, 팀 전체 케미 -3/턴 |
| 커뮤니케이션 | 0 | 해당 직원과의 모든 개인 간 케미 -1 |
| 멘탈 | -1 | 팀 전체 케미 -2/턴 (분위기 저하) |
| 멘탈 | 0 | 팀 전체 케미 -1/턴 |
| 충성도 | -1 | 불만 표출로 팀 케미 -1/턴 |

> 공통 스탯이 음수인 직원은 개인 능력과 무관하게 팀 분위기를 심각하게 저해할 수 있다. 채용 시 공통 스탯 확인이 중요하다.

- 개인 간 케미의 합산 평균이 팀 전체 케미에 반영됨

---

## 4. 팀 문화 태그

- **태그 예시**: `#야근문화` `#워라밸` `#빠르게빠르게` `#신중하게` `#음주회식` `#비음주` `#수평문화` `#수직문화` `#토론활발` `#지시따름`
- **결정 방식**: 팀원 특성 합산으로 자동 결정
- **재계산 주기**: 매 5턴

### 태그 영향

- **신규 채용 시**: 태그와 맞는 특성의 직원이 충성도 보너스
- **태그와 충돌하는 특성 직원**: 적응 기간 중 생산성 -10%

---

## 5. 케미에 영향 주는 행동들 (결정론적 레이어)

| 행동 | 케미 변동 |
|------|-----------|
| 복지비 증가 | +1~5 (항목별 상이) |
| 팀 야유회 | +5~15 |
| 프로젝트 성공 | +3~5 |
| 프로젝트 실패 | -3~5 |
| 팀원 해고 (정당) | -3~5 |
| 팀원 해고 (돌발) | -10~20 |
| 연봉 인상 | 해당 직원 케미 +2 |
| 성과급 지급 | 전체 +3 |
