# 경제 시스템 (Game Economy)

## 1. 경제 순환 개요

```
수입 (외주 잔금 + 서비스 매출 + 투자금 + 추가 수입)
  ↓
회사 자본 (Cash)
  ↓
지출 (연봉 + 운영비 + 복지비 + 마케팅비 + 이벤트 비용)
```

모든 금전 흐름은 회사 자본(Cash)을 중심으로 순환한다. 수입은 즉시 또는 조건부로 입금되며, 지출은 주기적으로 자동 차감된다.

---

## 2. 수입 계산

### 외주 프로젝트

- 선금: 계약 체결 즉시 수령 (계약금의 30%)
- 잔금: 납품 완료 후 수령 (계약금의 70% × 만족도 보정)
- 상세 → [수입원](../game-domain/revenue.md) 참조

### 자체 서비스

- 월 매출 = MAU × ARPU
- 4턴(1개월)마다 정산 페이즈에서 자동 입금
- 상세 → [수입원](../game-domain/revenue.md) 참조

### 투자금

- 시리즈별 일시 입금
- 투자 유치 성공 시 해당 턴에 즉시 반영
- 상세 → [투자](../game-domain/invest.md) 참조

### 추가 수입

- 지원사업, 라이선싱, 강연 등
- 이벤트 또는 특정 조건 충족 시 발생

---

## 3. 지출 계산

### 연봉

- 4턴(1개월)마다 자동 차감
- 계산: Σ(각 직원 연봉) ÷ 12

### 운영비

- 사무실 임대료
- 인프라 비용
- 서버 비용
- SW 구독료

### 복지비

- 선택한 복지 항목의 합산 금액
- 4턴마다 자동 차감

### 마케팅비

- 선택한 마케팅 채널의 합산 금액
- 4턴마다 자동 차감

상세 항목 → [지출](../game-domain/cost.md) 참조

---

## 4. 재무 건전성 지표

### 현금 잔액 (Cash Balance)

현재 보유 자본. 모든 수입/지출이 반영된 실시간 잔액.

### 런웨이 (Runway)

```
런웨이 = 현재 자본 ÷ 월간 순지출 = 남은 개월 수
```

| 런웨이 | 상태 |
|--------|------|
| 3개월 이하 | 경고 표시 |
| 1개월 이하 | 위기 알림 |

### 월간 번레이트 (Burn Rate)

```
번레이트 = 월 총지출 - 월 총수입
```

양수면 적자, 음수면 흑자 상태를 의미한다.

---

## 5. 복지 과잉 패널티 (한계효용 체감)

복지 투자에는 한계효용 체감 법칙이 적용된다.

| 조건 | 효과 |
|------|------|
| 복지비 합산 > 인원당 60만원/월 | 매 4턴 "나태함 이벤트" 확률 +15% |
| 나태함 이벤트 발생 시 | 해당 팀원 생산성 -10% (2턴 지속) |
| 연속 발생 시 | "복지가 너무 좋아서 자리 보전에만 신경" 특성 발현 |

---

## 6. 마케팅 효과 공식

```
마케팅 효과 = 기본 유입 × 서비스 완성도 보정 × 평점 보정
```

### 서비스 완성도 보정

| 완성도 | 보정 |
|--------|------|
| < 60 | 평점 하락 이벤트 확률 +30% |
| 60~79 | ×1.0 (표준) |
| 80+ | 바이럴 효과 추가 가능 |

### 평점 보정

| 평점 | 보정 |
|------|------|
| < 3.5 | 유입 < 이탈 → MAU 순감소 역전 |
| 3.5~3.9 | ×0.8 |
| 4.0~4.4 | ×1.0 |
| 4.5+ | ×1.3 + 바이럴 기회 |

---

## 7. 대출 메커니즘

| 항목 | 내용 |
|------|------|
| 활성화 조건 | 자본 500만원 이하 |
| 한도 | 보유 자산의 50% |
| 이자율 | 월 3~8% (난이도에 따라 상이) |
| 상환 기한 | 8~12턴 |
| 연속 대출 페널티 | 명성 -5, 투자 성공률 -10% |

---

## 8. 수치 연동 맵 (경제 관점)

```
[복지비↑] → 케미↑ → 충성도↑ → 이직↓ → 채용비↓
[복지 과잉] → 나태함 → 생산성↓
[마케팅비↑] → MAU↑ or ↓ (완성도 연동)
[외주 성공] → 명성↑ → 이력서 풀↑
[투자 유치] → 자본↑ → 채용/마케팅 가속
```
