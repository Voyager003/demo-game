# 조직 구조 (Game Organization)

## 1. 회사 성장 단계별 변화

| 단계 | 인원 | 변화 |
|------|------|------|
| 1인 창업 | 1명 | 대표가 직접 개발/영업, 기술이해도 스탯 활용 |
| 초기 팀 | 2~5명 | 단일 팀, 케미 단순 계산 |
| 소규모 스타트업 | 6~15명 | 팀 분리 옵션 해제, 팀장 임명 필요 |
| 스케일업 | 16~30명 | 부서 구조, 팀 간 협업 효율 |
| 중견기업 | 31명+ | 이사진 전원 충원 권장, 조직도 복잡 |

성장 단계 상세 → [회사](../game-domain/company.md) 참조

---

## 2. 팀 분리 시스템

- **활성화 조건**: 인원 6명 초과

### 분리 방식

| 분리 유형 | 기준 | 효과 |
|-----------|------|------|
| 프론트/백엔드 분리 | 개발팀 역할 기반 | 팀 내 케미 독립, 팀 간 협업 효율 별도 관리 |
| 개발/디자인 분리 | 직군 기반 | 디자이너-개발자 협업 효율 별도 수치 |
| 프로젝트팀 구성 | 특정 프로젝트 전담 | 해당 프로젝트 생산성 +15%, 메인 팀 인력 공백 |

- **팀 분리 시**: 각 팀 케미 독립 계산, 팀 간 협업 효율 수치 추가

---

## 3. 팀장 임명

- **조건**: 해당 직군 전문 스탯 합산 상위 1인
- **효과**: 팀 케미 안정화 +5, 딜레이 확률 -10%
- **리스크**: 팀장 이직 시 해당 팀 케미 -15, 팀원 동요 이벤트

---

## 4. 채용 메커니즘

```
이력서 풀 생성 (3~5장, 명성에 따라 품질)
  ↓
플레이어 선택 (면접 및 채용 확정: 피로도 2)
  ↓
수습 시작 (12턴)
  - 생산성 70~85%
  - 히든 특성 미발현
  ↓
전환 시점 (12턴 도달)
  → 정규직 전환: 연봉 협상 이벤트 가능
  → 전환 거부: 자동 퇴사, 팀 케미 영향
```

- **수습 중 해고**: 명성 -5 (소문 효과)
- 이력서 상세 → [채용/직군](../game-domain/career.md) 참조

---

## 5. 해고 메커니즘

### 해고 절차

1. 해고 선택 (피로도 2, 쿨타임 1턴) → 사유 선택

### 사유별 파급

| 사유 | 파급 | 부수 효과 |
|------|------|-----------|
| 성과부진 (정당) | 케미 -3~5, 친한 팀원 -10, 명성 ±0 | 나머지 안도 +2 가능 |
| 돌발해고 (사유없음) | 케미 -10~20, 전 팀원 -5, 명성 -10~15 | 잡플래닛 이벤트↑ |
| 구조조정 | 케미 -5~15, 명성 -5 | 연속 구조조정 시 명성 급락 |

3. **위로금 지급 시**: 명성 페널티 -50% 경감, 케미 +3

### 해고 후 연쇄 이벤트

- **잡플래닛 리뷰 폭탄**: 명성 -5~20, 이력서 풀↓
- **퇴사자 사이드프로젝트 유출**: 확률 10~30% (창업꿈나무 +20%)
- **남은 팀원 동요**: 이직욕구자 이탈 가속
- **위로금 지급 시 경감**
