# 게임 도메인 (Game Domain)

게임에서 **무엇이 존재하는지**를 `docs/old/mvp-core-loop.md` 기준으로 다시 정리한 도메인 허브입니다.

- `0순위`: 없으면 턴이 돌지 않는 최소 게임 루프의 도메인
- `1순위`: 게임을 게임답게 만드는 확장 도메인
- `범위 밖`: 문서에는 있으나 현재 MVP 코어 루프의 핵심 분류 밖에 있는 도메인

표준 용어는 [유비쿼터스 언어](../../new/game-domain/ubiquitous-language.md)를 정본으로 사용합니다.

---

## 먼저 읽을 문서

1. [MVP 코어 루프](../mvp-core-loop.md) — 0순위/1순위 기준
2. [유비쿼터스 언어](../../new/game-domain/ubiquitous-language.md) — 표준 용어와 코드 용어 대응표
3. 이 문서 — 기존 상세 문서의 위치와 읽기 순서

---

## 0순위 도메인

| 도메인 | 표준 용어 | 설명 | 관련 문서 |
|------|-----------|------|----------|
| **행동 자원** | 턴, 페이즈, 행동, 피로도, 쿨타임 | 대표가 한 턴에 무엇을 얼마나 할 수 있는지를 결정하는 최소 자원 체계 | [게임 진행](../game-system/game-process.md), [대표](./player.md) |
| **직원 기본 엔티티** | 직원, 직군, 전문 스탯, 업무 배정 | 프로젝트를 실제로 움직이는 사람과 역할 정의 | [채용/직군](./career.md) |
| **프로젝트** | 외주 프로젝트, 주수입원 프로젝트, 진척도, 납품, 클라이언트 만족도 | 외주 수주와 초기 주수입원 프로젝트 운영을 포함한 핵심 생산 단위 | [수입원](./revenue.md), [프로젝트 시스템](../game-system/game-project.md) |
| **경제** | 자본, 선금, 잔금, 월 반복 수입, 연봉, 운영비 | 돈이 들어오고 나가며 회사가 생존하는 최소 회계 단위 | [수입원](./revenue.md), [지출](./cost.md), [경제 시스템](../game-system/game-economy.md) |

## 1순위 도메인

| 도메인 | 표준 용어 | 설명 | 관련 문서 |
|------|-----------|------|----------|
| **대표** | 대표, 도메인, 대표 스탯, 고정 약점 | 게임 시작 선택과 플레이 스타일을 만드는 플레이어 측 도메인 | [대표](./player.md), [회사](./company.md) |
| **채용** | 채용 공고, 채용 후보, 이력서, 면접, 채용 확정, 수습 전환 | 직원을 들이고 유지하는 최소 인사 흐름 | [채용/직군](./career.md), [조직 구조](../game-system/game-organization.md) |
| **직원 확장 상태** | 공통 스탯, 충성도 | 전문 스탯 외에 직원의 안정성·유지비·잔류를 설명하는 상태값 | [채용/직군](./career.md) |
| **결정론적 이벤트** | 수습 전환, 연봉 협상, 납기 임박, 자본 위기 경고 | 현재 구현된 1순위 이벤트와 경고 체계 | [이벤트 시스템](../game-system/game-event.md) |
| **생존 상태** | 위기 상태, 유예 턴, 엔딩 등급 | 자본 고갈 이후의 버티기 상태와 게임 종료 조건 | [엔딩 시스템](../game-system/game-ending.md) |
| **팀 관계** | 특성, 팀 케미 | 직원 간 상호작용과 팀 분위기를 설명하는 도메인 | [특성](./trait.md), [케미스트리 시스템](../game-system/game-chemistry.md) |

## 범위 밖 도메인

| 도메인 | 현재 위치 | 설명 |
|------|----------|------|
| **투자** | [투자](./invest.md) | 중기 성장용 자금 조달 메커니즘 |
| **서비스 성장 지표** | [수입원](./revenue.md) | MAU, ARPU, 평점, 마케팅 노출도 등 Post-MVP 서비스 운영 지표 |
| **마케팅/복지 확장** | [지출](./cost.md) | 현재 핵심 루프의 필수 비용이 아닌 확장 비용 도메인 |
| **외부 환경 이벤트** | [이벤트 카탈로그](./event-catalog.md) | 시장/규제/랜덤 이벤트 테이블 |
| **기술 부채와 리팩토링** | [기술](./tech.md) | 외주 Lv1~2 코어 루프 바깥의 장기 기술 운영 도메인 |
| **조직 성장 단계와 이사진** | [회사](./company.md), [조직 구조](../game-system/game-organization.md) | 팀 분리, C-Level, 대형 조직 운영 |

## 기존 상세 문서 위치

| 문서 | 현재 분류 | 이번 읽기 목적 | 비고 |
|------|----------|---------------|------|
| [대표](./player.md) | 0순위 일부 + 1순위 핵심 | 리더십과 대표 스탯, 도메인 선택 | 0순위는 리더십→피로도 연결, 나머지는 1순위 |
| [채용/직군](./career.md) | 0순위 + 1순위 | 직원 엔티티, 전문 스탯, 채용, 공통 스탯 | 하나의 문서에 두 우선순위가 함께 들어 있음 |
| [수입원](./revenue.md) | 0순위 + 범위 밖 | 외주 프로젝트 수입, 주수입원 프로젝트 | 서비스 성장 지표와 기타 수입은 범위 밖 |
| [지출](./cost.md) | 0순위 + 범위 밖 | 연봉과 운영비 | 복지·마케팅은 범위 밖 |
| [회사](./company.md) | 1순위 + 범위 밖 | 도메인 선택과 회사 기본 맥락 | 성장 단계·명성·문화 태그는 범위 밖 비중이 큼 |
| [특성](./trait.md) | 1순위 | 특성과 공개 규칙, 케미 연결 | 구현보다 설계 비중이 큼 |
| [투자](./invest.md) | 범위 밖 | 후속 성장 도메인 | MVP 코어 루프 밖 |
| [이벤트 카탈로그](./event-catalog.md) | 범위 밖 | 외부 환경 이벤트 모음 | 현재 구현된 결정론 이벤트와 분리해서 읽어야 함 |
| [기술](./tech.md) | 범위 밖 | 기술 부채와 리팩토링 | 장기 운영 단계 도메인 |

## 시스템 문서와의 관계

도메인 문서는 **"무엇이 존재하는가"**를 다루고, [시스템 문서](../game-system/README.md)는 **"어떻게 작동하는가"**를 다룹니다.

예시:
- 도메인: `주수입원 프로젝트는 프로젝트의 한 종류다` → [유비쿼터스 언어](../../new/game-domain/ubiquitous-language.md), [수입원](./revenue.md)
- 시스템: `주수입원 프로젝트가 월 반복 수입을 어떻게 만든다` → [경제 시스템](../game-system/game-economy.md), [이벤트 시스템](../game-system/game-event.md)
