# 채용/직군 (Career)

## 개요

직원은 회사의 핵심 자원이다. 각 직원은 고용 형태, 공통 스탯, 직군별 전문 스탯을 보유하며, 이력서 시스템을 통해 채용된다.

- **직군(Job Role)**과 **고용 형태(Employment Type)**는 별도 속성이다.
- 직군은 **개발자 / 디자이너 / PM**으로 구분한다.
- 고용 형태는 **정규직 / 계약직 / 외주 사원**으로 구분한다.

---

## 고용 형태

### 정규직
- 채용 시 최초 **12턴(3개월)**은 수습 상태로 근무한다.
- **수습 기간 생산성**: 정규직 기준의 **70~85%**
- **수습 중 해고 시**: 명성(Reputation) **-5**
- 수습 기간 동안 숨겨진 특성이 점진적으로 공개된다 ([특성 공개 시스템](./trait.md) 참조).
- 수습 12턴 완료 후 **정규 전환 선택** 이벤트가 발생한다.
- **전환 수락 시**: 연봉 협상 이벤트 발생 가능. 이후 생산성 100%로 전환.
- **전환 거부 시**: 자동 퇴사 처리. 해당 팀의 케미스트리에 일시적 영향 발생.

### 계약직
- 정해진 계약 기간 동안 근무하는 인력이다.
- **수습 기간 없음**
- 계약 종료 시점에 **재계약 / 종료**를 선택할 수 있다.
- 정규직보다 고용 유연성이 높지만, 장기 충성도 관리에는 불리할 수 있다.

### 외주 사원
- 프로젝트 단위로 투입되는 외부 인력이다.
- **수습 기간 없음**
- 팀의 빈 자리를 단기적으로 메우는 용도에 가깝다.
- 내부 직원보다 팀 케미와 충성도 시스템의 직접 영향은 제한적으로 받는다.

## 공통 스탯

모든 직원은 직군과 무관하게 다음 5개의 공통 스탯을 보유한다. 공통 스탯은 **-1~5** 범위이다.

> **참고**: 공통 스탯의 범위는 -1~5이며, 대표(CEO) 스탯(1~10)이나 직원 전문 스탯(1~10)과는 별개이다.

| 스탯 | 설명 | 범위 |
|------|------|------|
| **체력 (Stamina)** | 야근 감내 능력, 번아웃 저항 | -1~5 |
| **커뮤니케이션 (Communication)** | 협업 효율, 오해 발생 빈도 | -1~5 |
| **멘탈 (Mental)** | 스트레스 저항, 돌발 이벤트 대응력 | -1~5 |
| **성장속도 (GrowthRate)** | 매 N턴마다 전문 스탯 자동 증가율 | -1~5 |
| **충성도 (Loyalty)** | 이직 확률, 갈등 시 이탈 저항력 | -1~5 |

### 공통 스탯 구간별 효과

음수 스탯은 심각한 디버프를 유발한다. 디버프 상태의 직원은 팀 전체에 부정적 영향을 미치므로, 채용 시 주의 깊은 판단이 필요하다.

#### 체력 (Stamina)

| 구간 | 효과 |
|------|------|
| **-1** (심각) | 기본 업무 효율 40%. 야근 지시 시 즉시 번아웃 발생. 매 4턴 병가 확률 30%. |
| **0** (약점) | 기본 업무 효율 60%. 번아웃 확률 +30%. 야근 1턴만으로 번아웃 위험. |
| **1~2** (보통) | 일반적 업무 효율. 연속 야근 시 번아웃 누적. |
| **3~4** (우수) | 야근 시 생산성 페널티 감소. 번아웃 저항력 높음. |
| **5** (최상) | 야근 2연속까지 페널티 없음. 번아웃 거의 면역. |

#### 커뮤니케이션 (Communication)

| 구간 | 효과 |
|------|------|
| **-1** (심각) | 재작업 확률 +25%. 해당 직원과의 모든 개인 간 케미 -3. 팀 케미 -3/턴. |
| **0** (약점) | 재작업 확률 +15%. 해당 직원과의 모든 개인 간 케미 -1. |
| **1~2** (보통) | 소폭 재작업 확률 증가. 일반적 협업 수준. |
| **3~4** (우수) | 재작업 확률 감소. 팀 내 오해 발생 빈도 낮음. |
| **5** (최상) | 재작업 확률 최소화. 팀 케미에 +1/턴 기여. |

#### 멘탈 (Mental)

| 구간 | 효과 |
|------|------|
| **-1** (심각) | 스트레스 이벤트 시 영향 2배. 돌발 병가(4턴마다 20% 확률). 팀 전체 케미 -2/턴. |
| **0** (약점) | 스트레스 이벤트 시 영향 1.5배. 부정적 이벤트 후 회복에 +2턴. |
| **1~2** (보통) | 약간 취약. 스트레스 이벤트 시 소폭 성과 하락. |
| **3~4** (우수) | 높은 회복력. 스트레스 이벤트에도 성과 유지. |
| **5** (최상) | 스트레스 면역 수준. 위기 상황에서 오히려 팀 안정화 기여. |

#### 성장속도 (GrowthRate)

| 구간 | 효과 |
|------|------|
| **-1** (심각) | 전문 스탯 자동 성장 불가. 외부 교육 효과도 50% 감소. |
| **0** (약점) | 자동 성장 없음. 외부 교육 액션으로만 전문 스탯 성장 가능. |
| **1~2** (보통) | 느린 성장. 매 12턴마다 전문 스탯 1개 +1. |
| **3~4** (우수) | 빠른 성장. 매 8턴마다 전문 스탯 1개 +1. |
| **5** (최상) | 매 6턴마다 전문 스탯 1개 +1. 외부 교육 효과 2배. |

#### 충성도 (Loyalty)

| 구간 | 효과 |
|------|------|
| **-1** (심각) | 매 턴 30% 확률로 이탈 시도. 헤드헌팅에 무조건 반응. |
| **0** (약점) | 헤드헌팅에 극도로 취약. 연봉 불만 시 즉시 이직 결심. |
| **1~2** (보통) | 보통 수준의 이직 리스크. 조건 악화 시 이직 고려. |
| **3~4** (우수) | 안정적. 일반적 헤드헌팅에 무반응. 팀 갈등에도 잔류 의지. |
| **5** (최상) | 헌신적. 위기 상황에서도 무급 잔류 의지. 팀 사기에 긍정적 영향. |

## 직군 1: 개발자 (Developer)

회사의 기술적 핵심. 프로젝트의 실질적 구현을 담당한다.

### 전문 스탯

전문 스탯은 **1~10** 범위이다.

| 스탯 | 설명 |
|------|------|
| **구현속도 (CodingSpeed)** | 코드 작성 및 기능 구현 속도 |
| **코드품질 (CodeQuality)** | 버그 발생률, 유지보수 용이성 |
| **문제해결력 (ProblemSolving)** | 기술적 난관 돌파, 디버깅 효율 |
| **기술스택폭 (TechBreadth)** | 다양한 기술 스택 대응 능력 |
| **보안감각 (SecuritySense)** | 보안 취약점 사전 방지, 보안 이슈 대응 |

### 프로젝트 난이도 티어

전문 스탯 5개의 합산 수치로 수행 가능한 프로젝트 난이도가 결정된다.

| 티어 | 스탯 합산 | 프로젝트 예시 |
|------|----------|-------------|
| **Lv1** | 10~19 | 랜딩페이지, 단순 관리자 페이지 |
| **Lv2** | 20~34 | 커머스, 예약 시스템 |
| **Lv3** | 35~49 | 플랫폼, 실시간 기능 (채팅, 알림) |
| **Lv4** | 50+ | AI 연동, 대규모 트래픽 처리 시스템 |

> 팀에 배정된 개발자들의 스탯 합산이 프로젝트 요구 티어에 미달하면 품질 저하 및 딜레이 패널티가 발생한다.

---

## 직군 2: 디자이너 (Designer)

제품의 시각적 품질과 사용자 경험을 담당한다.

### 전문 스탯

전문 스탯은 **1~10** 범위이다.

| 스탯 | 설명 |
|------|------|
| **UI감각 (UISense)** | 시각적 완성도, 디자인 퀄리티 |
| **UX사고력 (UXThinking)** | 사용자 흐름 설계, 사용성 개선 |
| **작업속도 (WorkSpeed)** | 디자인 산출물 작업 속도 |
| **브랜딩감각 (BrandingSense)** | 브랜드 아이덴티티 구축, 일관성 유지 |
| **프로토타이핑 (Prototyping)** | 프로토타입 제작 속도 및 완성도 |

### 디자이너 역할
- 프로젝트 시작 단계에서 디자인 산출물을 생성한다.
- 디자이너가 없는 프로젝트는 UI 품질 페널티가 적용된다.
- 브랜딩감각이 높은 디자이너는 주수입원 프로젝트의 브랜드 가치에 기여한다.

## 직군 3: PM (Project Manager)

프로젝트 일정과 품질을 관리하며, 클라이언트와의 소통을 담당한다.

### 전문 스탯

전문 스탯은 **1~10** 범위이다.

| 스탯 | 설명 |
|------|------|
| **일정관리 (ScheduleManagement)** | 프로젝트 일정 수립 및 준수율 |
| **요구사항분석 (RequirementAnalysis)** | 클라이언트 요구사항의 정확한 파악 |
| **리스크감지 (RiskDetection)** | 잠재적 위험 요소 사전 식별 |
| **고객응대 (ClientManagement)** | 클라이언트 만족도, 컴플레인 대응 |
| **팀조율력 (TeamCoordination)** | 팀원 간 업무 배분 및 갈등 조율 |

### PM 부재 시 패널티

PM이 배정되지 않은 프로젝트에는 다음 패널티가 매 프로젝트 턴마다 적용된다.

| 패널티 항목 | 수치 |
|------------|------|
| **딜레이** | +15% |
| **재작업** | +10% |

> PM이 없으면 일정 관리가 느슨해지고, 요구사항 오해로 인한 재작업이 빈번해진다.

## 이력서 시스템

직원 채용은 이력서 시스템을 통해 이루어진다.

### 이력서 생성 규칙
- 매 **채용 턴**마다 **3~5장**의 이력서가 자동 생성된다.
- 회사 **명성(Reputation)**에 따라 이력서 퀄리티 분포가 변동한다.
  - 명성 높음: 고스펙 이력서 비율 증가
  - 명성 낮음: 저스펙 이력서 위주로 생성
- 각 이력서에는 지원자의 **희망 고용 형태**가 함께 표시된다.

### 이력서 구성 항목

| 항목 | 설명 | 공개 여부 |
|------|------|----------|
| **이름** | 지원자 이름 | 공개 |
| **직군** | 개발자 / 디자이너 / PM | 공개 |
| **고용 형태** | 정규직 / 계약직 / 외주 사원 | 공개 |
| **경력** | 경력 연차 | 공개 |
| **전문 스탯** | 직군별 전문 스탯 수치 (1~10) | 공개 |
| **기본 스탯** | 공통 스탯 수치 (-1~5) | 공개 |
| **특성** | 보유 특성 목록 | **일부만 공개** (힌트 포함) |
| **희망 연봉** | 지원자가 요구하는 연봉 | 공개 |

> 특성은 이력서에 1~2개만 확실히 표시되며, 나머지는 힌트 텍스트로 추정만 가능하다. 정규직은 수습 기간이 주요 공개 구간이 된다. 상세는 [특성](./trait.md) 참조.

### 이력서 예시

```
┌─────────────────────────────────────┐
│            이력서                     │
├─────────────────────────────────────┤
│ 이름: 김서준                          │
│ 직군: 개발자 (Developer)              │
│ 고용 형태: 정규직                     │
│ 경력: 3년차                          │
├─────────────────────────────────────┤
│ [전문 스탯]                (1~10)    │
│  구현속도     ████████░░  8          │
│  코드품질     ██████░░░░  6          │
│  문제해결력    █████░░░░░  5          │
│  기술스택폭    ████░░░░░░  4          │
│  보안감각     ███░░░░░░░  3          │
├─────────────────────────────────────┤
│ [기본 스탯]                (-1~5)    │
│  체력        ▰▰▰▱▱▱▱  2            │
│  커뮤니케이션  ▰▰▰▰▱▱▱  3           │
│  멘탈        ▰▰▱▱▱▱▱  1            │
│  성장속도     ▰▰▰▰▰▱▱  4           │
│  충성도       ▰▰▰▱▱▱▱  2           │
├─────────────────────────────────────┤
│ [특성]                               │
│  ✅ 야근 체질 — 야근 시 피로도 50% 감소 │
│  💬 "업무 스타일이 독특해 보인다"       │
│  🔒 ??? — 수습 기간 중 공개           │
├─────────────────────────────────────┤
│ 희망 연봉: 4,800만 원                 │
└─────────────────────────────────────┘
```

> 기본 스탯의 바 차트는 -1~5 범위를 반영한다. -1은 빈 바 + 경고 표시로 시각화한다.
