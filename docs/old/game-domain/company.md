# 회사 (Company)

## 개요

회사는 플레이어(대표)가 운영하는 IT 기업 엔티티다. 게임 시작 시 회사를 설립하며, 이후 모든 경영 판단의 기준이 된다.

## 회사 엔티티 정의

| 속성 | 설명 |
|------|------|
| **이름** | 플레이어가 직접 입력하는 회사명 |
| **카테고리** | 아래 5개 중 택 1 (게임 시작 시 선택) |
| **성장 단계** | 인원 수에 따라 자동 전환되는 회사 규모 |
| **명성 (Reputation)** | 업계 내 평판 수치 (0~100) |
| **문화 태그** | 회사 문화를 나타내는 태그 (케미스트리 시스템과 연동) |

---

## 명성 (Reputation)

명성은 **0~100** 범위의 수치로, 회사의 업계 내 평판을 나타낸다.

### 영향 범위

| 영역 | 효과 |
|------|------|
| **이력서 풀 품질** | 명성이 높을수록 고스펙 이력서가 채용 풀에 등장할 확률 증가 |
| **투자 유치** | 투자 심사 시 명성 기반 가산점 부여, 낮으면 투자 라운드 자체가 제한될 수 있음 |
| **미디어 노출** | 명성 50 이상부터 미디어 이벤트(인터뷰, 기사) 발생 가능, 마케팅 효율에 간접 보정 |

### 명성 변동 요인

- **상승**: 프로젝트 성공 납품, 주수입원 프로젝트 성과, 투자 유치 성공, 긍정적 이벤트 선택
- **하락**: 프로젝트 실패/지연, 수습 기간 해고, 대량 퇴사, 부정적 이벤트

---

## 카테고리

게임 시작 시 5개 카테고리 중 하나를 선택한다. 카테고리에 따라 외주 프로젝트 풀의 특성과 초기 **주수입원 프로젝트** 콘셉트가 달라진다.

| 카테고리 | 설명 | 외주 풀 특성 | 주수입원 프로젝트 콘셉트 |
|----------|------|-------------|-------------------------|
| **B2B SaaS** | 기업용 솔루션 | 관리자 페이지, 대시보드 | 구독 기반 SaaS |
| **커머스 플랫폼** | 전자상거래 | 쇼핑몰, 예약 시스템 | 커머스 앱 |
| **커뮤니티/미디어** | 소셜/콘텐츠 | 커뮤니티, CMS | 미디어 플랫폼 |
| **핀테크** | 금융 기술 | 결제, 정산 시스템 | 핀테크 서비스 |
| **헬스케어 IT** | 의료 IT | EMR, 예약 | 헬스케어 앱 |

### 카테고리별 특징

- **B2B SaaS**: 안정적인 외주 수요, 프로젝트 단가 중상. 초기 주수입원 프로젝트는 구독 기반 SaaS 성격을 가진다.
- **커머스 플랫폼**: 외주 물량이 많고 난이도 분포 넓음. 초기 주수입원 프로젝트는 거래액 기반 수수료 모델에 가깝다.
- **커뮤니티/미디어**: 초기 외주 단가 낮지만 물량 풍부. 초기 주수입원 프로젝트는 트래픽 기반 광고 수익 모델에 가깝다.
- **핀테크**: 외주 프로젝트 단가 최상, 그러나 보안 요구 높음. 초기 주수입원 프로젝트는 금융 서비스 성격을 가진다.
- **헬스케어 IT**: 규제 준수 필요, 외주 프로젝트 장기 계약 비중 높음. 초기 주수입원 프로젝트는 의료 IT 서비스 성격을 가진다.

## 성장 단계

회사의 성장 단계는 고용 인원 수에 따라 자동으로 전환된다. 각 단계마다 운영 방식과 가능한 시스템이 달라진다.

| 단계 | 인원 | 특징 |
|------|------|------|
| **1인 창업** | 1명 | 대표가 직접 개발/영업, 외주 Lv1만 가능 |
| **초기 팀** | 2~5명 | 단일 팀, 케미 계산 단순 |
| **소규모 스타트업** | 6~15명 | 팀 분리 옵션 해제, 팀장 임명 필요 |
| **스케일업** | 16~30명 | 부서 구조 도입, 팀 간 협업 효율 |
| **중견기업 진입** | 31명+ | 이사진 전원 충원 권장, 조직도 복잡도 증가 |

### 단계별 상세

#### 1인 창업 (1명)
- 대표가 개발, 영업, 관리를 모두 수행한다.
- 외주 프로젝트는 Lv1 난이도만 수주 가능하다.
- 첫 채용이 이루어지면 자동으로 다음 단계로 전환된다.

#### 초기 팀 (2~5명)
- 하나의 팀으로 운영되며, 별도의 팀 분리가 불가하다.
- 케미스트리 계산이 단순하여 팀 관리 부담이 적다.
- 외주 Lv2까지 가능하다.

#### 소규모 스타트업 (6~15명)
- 팀 분리 기능이 해제되어 복수 팀 운영이 가능하다.
- 각 팀에 팀장을 임명해야 하며, 팀장 미임명 시 생산성 패널티가 발생한다.
- 외주 Lv3까지 가능하다.

#### 스케일업 (16~30명)
- 부서(개발부, 디자인부, 기획부) 구조가 도입된다.
- 팀 간 협업 효율이 조직 구조에 따라 달라진다.
- 이사진 채용이 가능해진다.

#### 중견기업 진입 (31명+)
- 이사진(CTO, CMO, COO, CFO) 전원 충원이 권장된다.
- 조직도 복잡도가 증가하여 관리 비용이 상승한다.
- 주수입원 프로젝트를 서비스형 성장 메커니즘으로 확장할 조건이 충족된다.
