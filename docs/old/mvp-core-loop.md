# MVP 코어 루프 (Minimum Viable Game Loop)

## 목적

최소한의 게임 플레이 가능 범위를 정의한다.

함께 읽을 문서:
- [게임 도메인 허브](./game-domain/README.md) — 현재 문서를 0순위/1순위 기준으로 다시 묶은 인덱스
- [유비쿼터스 언어](../new/game-domain/ubiquitous-language.md) — 문서 표준 용어와 코드 용어 대응표

## MVP 스코프 정의

### 0순위 — 게임 동작의 필요조건

이것이 없으면 게임이 **작동하지 않는다**. 턴이 돌아가고, 돈이 들어오고, 돈이 나가고, 끝나는 최소 골격.

현재 구현된 결정론적 핵심 계산(프로젝트 진척도, 클라이언트 만족도, 주수입원 프로젝트 실효 매출)은 0순위로 본다.

| 시스템 | 0순위 범위 | 참조 문서 |
|--------|-----------|----------|
| **턴 진행** | 5 Phase 순환 (이벤트→의사결정→실행→정산→보고) | [게임 진행](./game-system/game-process.md) |
| **행동 자원** | 피로도와 쿨타임을 통한 행동 제한 메커니즘 | [게임 진행](./game-system/game-process.md), [대표](./game-domain/player.md) |
| **프로젝트** | 외주 Lv1 계약 + 주수입원 프로젝트 운영 → 진척도 계산 → 납품/정산 | [프로젝트 시스템](./game-system/game-project.md), [수입원](./game-domain/revenue.md) |
| **경제** | 수입(외주 선금/잔금, 주수입원 프로젝트 반복 수입), 지출(연봉, 운영비), 자본 잔액 계산 | [경제 시스템](./game-system/game-economy.md), [지출](./game-domain/cost.md) |
| **직원** | 직원 엔티티, 직군, 전문 스탯, 업무 배정 | [채용/직군](./game-domain/career.md) |
| **UI** | 자본/인원/프로젝트 현황 표시, 턴 종료 버튼 | [UI 설계](./game-system/game-ui.md) |

### 1순위 — 게임을 게임답게 만드는 요소

| 시스템 | 1순위 범위 | 참조 문서 |
|--------|-----------|----------|
| **대표 스탯 전체** | 5개 스탯 + 고정 약점 + 도메인별 초기값 | [대표](./game-domain/player.md) |
| **채용** | 채용 공고 → 이력서 생성 → 면접 → 채용 확정 → 수습 전환 | [채용/직군](./game-domain/career.md) |
| **직원 공통 스탯** | -1~5 범위, 디버프 효과 | [채용/직군](./game-domain/career.md) |
| **특성** | 3개 고정 특성, 구조적 공개 시스템 (힌트→수습 공개) | [특성](./game-domain/trait.md) |
| **프로젝트 Lv2** | Lv2 난이도 외주 추가 | [프로젝트 시스템](./game-system/game-project.md) |
| **생존 시스템** | 런웨이 표시, 파산 유예(4~8턴), 직원 충성도 잔류 | [엔딩 시스템](./game-system/game-ending.md) |
| **결정론적 이벤트** | 수습 전환, 연봉 협상, 납기 알림 등 | [이벤트 시스템](./game-system/game-event.md) |
| **팀 케미** | 팀 전체 케미(0~100), 특성 충돌/시너지 | [케미스트리](./game-system/game-chemistry.md) |
| **엔딩 확장** | 생존(C) + 외주 강자(B) 추가 | [엔딩 시스템](./game-system/game-ending.md) |
| **UI 확장** | 대시보드 5패널, 알림 시스템, 이벤트 로그 | [UI 설계](./game-system/game-ui.md) |
| **엔딩** | 파산(F) 1종 — 자본 고갈 시 게임 종료 | [엔딩 시스템](./game-system/game-ending.md) |


### 제외 (Post-MVP)

| 시스템 | 제외 이유 |
|--------|----------|
| 투자 유치 | 중기 성장 메커니즘 — 기본 생존 루프에 불필요 |
| 서비스형 성장 메커니즘 | MAU, ARPU, 평점, 마케팅 노출도 등은 현재 MVP 반복 수입 모델보다 복잡하다 |
| 확률적/연쇄 이벤트 | 기본 결정론적 인과관계 먼저 검증 |
| 마케팅 시스템 | 서비스형 성장 메커니즘 없이 우선순위가 낮다 |
| 히든 엔딩 | 기본 엔딩(생존/파산)만 먼저 구현 |
| 이사진(C-Level) | 조직 복잡도 후순위 |
| 팀 분리 시스템 | 소규모(1~5인) 범위에서는 불필요 |
| 기술 부채/리팩토링 | 외주 Lv1~2 수준에서는 부채 누적이 느림 |

## 코어 루프 흐름

```
게임 시작
  도메인 선택 → 대표 초기 스탯 결정
  회사명 입력
  초기 자본: 2,000만원

  ↓

[턴 루프]
  Phase 1: 이벤트 (결정론적 이벤트만)
    - 수습 전환 이벤트
    - 연봉 협상 요청
    - 외주 납기 임박 알림

  Phase 2: 의사결정 (피로도 게이지 내 행동 선택)
    경영: 채용 공고(3) → 면접/채용(2) → 해고(2) → 연봉 조정(1)
    프로젝트: 외주 계약(3) → 업무 배분(1) → 야근 지시(2)
    무료: 대시보드 열람(0) → 직원 정보(0) → 턴 종료(0)

  Phase 3: 실행 (자동)
    - 진행 중 프로젝트 진척도 계산
    - 팀원 체력 소모
    - 수습 카운트 증가
    - 쿨타임 감소

  Phase 4: 정산 (자동)
    매 턴: 팀 케미 재계산
    4턴마다: 연봉 차감, 운영비 차감, 외주 잔금 수령

  Phase 5: 결과 보고
    - 턴 요약 대시보드
    - 잔여 피로도/쿨타임 표시
    - 임박 이벤트 예고 (납기, 수습 전환, 연봉 지급)
    - 실패 조건 근접 경고

  ↓

[엔딩 판정]
  자본 0원 이하 → 위기 상태 → 유예 4~8턴 → 미회복 시 F등급 (파산)
  50턴 생존 + 적자 없음 → C등급 (생존)
  외주 수익 20턴+ 흑자 → B등급 (외주 강자)
```

## MVP에서 사용하는 행동 목록

피로도와 쿨타임이 있는 행동만 나열한다 (무료 행동 제외).

| 행동 | 피로도 | 쿨타임 | MVP 역할 |
|------|--------|--------|---------|
| 채용 공고 게시 | 3 | 2턴 | 이력서 풀 생성 |
| 면접 및 채용 확정 | 2 | 0 | 직원 채용 |
| 해고 | 2 | 1턴 | 인력 조정 |
| 연봉 조정 | 1 | 4턴 | 비용/충성도 관리 |
| 외주 계약 체결 | 3 | 1턴 | 수입 확보 |
| 업무 배분 변경 | 1 | 0 | 생산성 최적화 |
| 야근 지시 | 2 | 1턴 | 단기 생산성 부스트 |

## MVP 밸런스 기준

### 경제 밸런스

| 항목 | 수치 |
|------|------|
| 초기 자본 | 2,000만원 |
| CEO만 운영 시 월 지출 | ~200만원 (운영비) |
| 첫 채용 후 월 지출 | ~500만원 (운영비 + 1인 연봉) |
| Lv1 외주 선금(30%) | 200~400만원 |
| Lv1 외주 잔금(70%) | 500~900만원 |
| Lv1 외주 소요 | 4~6턴 |

### 핵심 긴장 포인트

| 시점 | 이벤트 |
|------|--------|
| **턴 1~2** | 게임 시작, 대시보드 파악 |
| **턴 3~4** | 첫 채용 or 첫 외주 계약 결정 (리더십 3이면 피로도 8 = 채용3+외주3+여유2) |
| **턴 8~12** | **첫 현금 위기** — 선금 소진, 잔금 미수령 구간. 채용한 직원 연봉 첫 지급. |
| **턴 12~16** | 수습 전환 결정 + 두 번째 프로젝트 방향 판단 |
| **턴 20~** | 안정기 진입 or 연쇄 위기 |

## MVP에서 검증할 것

1. **기본 루프의 재미**: 채용 → 프로젝트 수주 → 납품 → 수입 사이클이 만족스러운가
2. **피로도/쿨타임**: 제한된 행동 수가 의미 있는 의사결정을 유도하는가
3. **현금 흐름 긴장감**: 런웨이 관리가 적절한 스릴을 제공하는가
4. **직원 스탯/특성 체감**: 팀 구성이 프로젝트 결과에 눈에 띄는 차이를 만드는가
5. **CEO 트레이드오프**: 고정 약점이 게임 중반부터 체감되는가
