# 2026-04-30 작업 로그

## 작업 주제
- 회사 성장 단계 시스템을 도메인으로 추가
- 운영 난이도 혼합형 레벨 시스템을 객체 지향 정책 구조로 구현
- 단계별 운영 압박, 투자 게이트, 승급 로그를 기존 턴/정산 흐름에 연결

## 오늘 반영한 내용
- `companyStage` 상태를 `GameState`에 추가
- `solo -> earlyTeam -> startup -> scaleUp` 4단계 회사 성장 구조 도입
- 회사 단계 승급 규칙을 `CompanyStageProgressionPolicy`로 분리
- 단계별 운영 압박을 `CompanyStagePressurePolicy`로 분리
- 단계별 투자 시도 가능 여부를 `CompanyStageInvestmentGatePolicy`로 분리
- 월 정산 시점에만 회사 단계 승급 여부를 자동 판정하도록 구현
- 단계 오버헤드를 월 운영비에 반영
- 단계 압박을 프로젝트 진척도와 주수입원 실효 수입 결정론 계산에 반영
- 투자 유치 액션이 현재 회사 단계 게이트를 통과해야만 실행되도록 변경
- 대시보드와 액션 메뉴에 현재 회사 단계, 다음 단계 조건, 단계 압박 요약, 투자 차단 사유를 노출

## 주요 의사결정
- `레벨` 대신 `회사 성장 단계`라는 이름 있는 단계 구조를 채택한다.
- 단계는 `인원 + 경제 + 평판` 복합 조건으로 판정한다.
- 단계는 한 번 오르면 내려가지 않으며, 상태 악화는 단계 하락이 아니라 활성 패널티로 표현한다.
- 승급 판정은 `매 턴`이 아니라 `월 정산 시점(4턴마다)`에만 수행한다.
- 단계별 압박은 `조직 복잡도 + 재무 압박` 혼합형으로 둔다.
- 팀 분리나 팀장 임명은 이번 1차에서 실제 상태로 만들지 않고, 규칙 기반 압박으로만 반영한다.
- `Lv2 외주` 같은 레벨 외주 시스템은 회사 성장 단계가 대체하는 방향으로 본다.

## 구현 메모
- 새 도메인 타입:
  - `CompanyStage`
  - `CompanyStageState`
  - `CompanyStagePreview`
  - `CompanyStageRequirementSnapshot`
- 기본 승급 문턱:
  - `earlyTeam`: 직원 2+, 자본 1,200+, 회사 평가 25+
  - `startup`: 직원 6+, 자본 3,000+, 회사 평가 40+, 실효 반복수입 180+
  - `scaleUp`: 직원 12+, 자본 8,000+, 회사 평가 55+, 실효 반복수입 350+
- 단계 압박은 기존 결정론 레이어에 `externalEffects`로 주입했다.
- 정산, 주수입원 미리보기, 외주 완료 예측이 모두 같은 회사 단계 압박 정책을 공유하도록 맞췄다.
- 투자 심사는 기존 `InvestmentReviewPolicy`를 유지하고, 사전 게이트만 회사 단계 정책으로 분리했다.
