# UI/시스템 설계 (Game UI)

## 1. 대시보드 구성

메인 화면은 5개의 패널로 구성되며, 플레이어가 한눈에 회사 상태를 파악할 수 있도록 설계한다.

| 패널 | 표시 정보 |
|------|-----------|
| 재무 현황 | 현재 자본, 월 수입/지출 예상, 런웨이 |
| 팀 현황 | 전체 인원, 팀 케미, 진행 중 프로젝트 목록 |
| 서비스 현황 | MAU, 평점, 완성도, 기술 부채 |
| 이벤트 로그 | 최근 5턴 발생 이벤트 요약 (레이어 색상 태그 포함) |
| 알림 | 임박 연봉 지급일, 수습 전환 대상, 경고 |

- 재무 현황 패널의 런웨이는 현재 현금 흐름 기준으로 몇 턴 버틸 수 있는지를 표시한다.
- 팀 현황 패널에서 개별 팀원 클릭 시 상세 정보(스킬, 역할, 충성도 구간)를 확인할 수 있다.
- 이벤트 로그는 스크롤하여 전체 이력을 확인할 수 있으며, 중요도별 및 **레이어별** 필터링을 지원한다.
- 각 이벤트 앞에 **레이어 색상 태그** 표시: 결정론적(파랑), 확률적(노랑), 연쇄 효과(빨강).
- 연쇄 효과 이벤트는 클릭 시 선행 이벤트 체인을 펼쳐볼 수 있다.

## 2. 수치 가시성 설계

> 어떤 정보를 공개하고 숨길지가 게임의 분위기와 난이도에 직결된다.

| 수치 | 공개 방식 | 비고 |
|------|-----------|------|
| 회사 자본 | 정확히 공개 | |
| 팀 전체 케미 | 정확히 공개 | |
| 개인 간 케미 | 힌트 텍스트 | "요즘 두 사람이 자주 부딪히는 것 같다" |
| 직원 충성도 | 구간 표시 (높음/보통/낮음) | 정확한 수치 비공개 |
| 히든 특성 | 발현 전까지 비공개 | |
| 기술 부채 | 정확히 공개 | IT 현실 인지 유도 |
| 투자 심사 가중치 | CFO 채용 시 공개 | 정보 비대칭 해소 보상 |

설계 원칙:

- 재무 관련 수치는 투명하게 공개하여 전략적 의사결정을 지원한다.
- 인간관계 관련 수치는 간접적으로 전달하여 현실감을 부여한다.
- 일부 수치는 특정 조건(CFO 채용 등) 달성 시 해금되어 정보 획득 자체가 보상이 된다.
- 히든 특성은 발현 조건 충족 시 최초 1회 연출과 함께 공개된다.

## 3. 저장 시스템

| 기능 | 설명 |
|------|------|
| 자동 저장 | 매 턴 종료 시 |
| 수동 저장 | 슬롯 3개 |
| 턴 되돌리기 | 직전 1턴만 (어려움 난이도 비활성화) |
| 이벤트 선택 취소 | 불가 (선택의 무게감 유지) |

- 자동 저장은 별도 슬롯에 기록되며, 수동 저장 슬롯과 독립적으로 관리된다.
- 턴 되돌리기는 보통/쉬움 난이도에서만 사용 가능하며, 게임당 사용 횟수 제한은 없다.
- 이벤트 선택 후에는 되돌릴 수 없으므로, 선택 전 확인 다이얼로그를 표시한다.
- 수동 저장 슬롯에는 턴 수, 자본, 팀원 수, 엔딩 진행도가 미리보기로 표시된다.

## 4. 튜토리얼 / 온보딩

- 첫 게임 진입 시 3~5턴 가이드 모드
- 가이드 모드 효과: 메인 이벤트 빈도 감소, 자본 감소 속도 50% 완화
- 각 시스템 첫 발생 시 툴팁 표시 (이후 비활성화 가능)
- 스킵 가능

가이드 모드 상세:

| 턴 | 가이드 내용 |
|----|-------------|
| 1턴 | 대시보드 UI 설명, 턴 진행 방법 안내 |
| 2턴 | 채용 시스템 소개, 첫 직원 채용 유도 |
| 3턴 | 프로젝트/외주 시스템 소개, 첫 외주 수주 유도 |
| 4턴 | 이벤트 시스템 소개, 선택지 결과 미리보기 제공 |
| 5턴 | 가이드 종료, 정상 난이도 적용 |

- 가이드 모드 중에도 자유로운 행동이 가능하며, 가이드 지시를 무시해도 페널티는 없다.
- 재시작 시 가이드 모드를 다시 활성화할 수 있다.

## 5. 알림 시스템

Phase 5 (결과 보고)에서 다음 항목이 자동 알림된다:

| 알림 항목 | 시점 | 우선순위 |
|-----------|------|----------|
| 수습 전환 임박 | D-2턴 | 보통 |
| 외주 납기 임박 | D-3턴 | 높음 |
| 월간 연봉 지급일 | D-1턴 | 높음 |
| 투자 심사 결과 예정 | D-1턴 | 보통 |
| 실패 조건 근접 경고 (자본 위기) | 즉시 | 긴급 |
| 실패 조건 근접 경고 (케미 위기) | 즉시 | 긴급 |

알림 표시 규칙:

- 긴급 알림은 화면 중앙 팝업으로 표시되며, 확인 버튼을 눌러야 진행 가능하다.
- 높음 알림은 대시보드 알림 패널 상단에 강조 표시된다.
- 보통 알림은 알림 패널에 일반 텍스트로 표시된다.
- 동일 항목에 대한 알림은 중복 표시하지 않으며, 가장 긴급한 상태만 표시한다.
