# 게임 진행 (Game Process)

## 1. 턴 구조

| 단위 | 환산 | 비고 |
|------|------|------|
| 1턴 | 1주일 | 기본 시간 단위 |
| 4턴 | 1개월 | 연봉 지급 주기 |
| 12턴 | 1분기 | 세금 신고 주기 |
| 52턴 | 1년 | 연말 정산 주기 |

---

## 2. 턴 내 페이즈 순서

매 턴은 아래 5개 페이즈를 순서대로 진행한다.

### Phase 1: 이벤트 발생 (Event Phase)

- 랜덤 이벤트 판정 (주사위 굴림)
- 외부 환경 이벤트 체크 (시장 트렌드, 법규제 변경)
- 히든 특성 발현 판정 (매 4턴마다 실행)
- 긴급 이벤트 발생 시 → 긴급 액션 슬롯 소모로 즉시 대응 가능
- 이벤트가 없으면 이 페이즈는 자동 스킵

### Phase 2: 의사결정 (Decision Phase)

- **메인 액션** 3회 실행 (리더십에 따라 최대 5회)
- **자유 액션** 무제한 실행
- 순서 자유 (메인과 자유 액션을 섞어서 실행 가능)

**메인 액션 예시:**
- 채용, 해고
- 외주 계약 체결
- 투자 신청
- 리팩토링 착수
- 팀 분리
- 교육/컨퍼런스 파견

**자유 액션 예시:**
- 복지 설정 변경
- 마케팅 예산 조정
- 대시보드 열람
- 업무 배분 변경
- 연봉 조정

### Phase 3: 실행/진행 (Execution Phase)

> 자동 처리 (플레이어 개입 없음)

- 진행 중인 프로젝트 진척도 계산: 투입 인력 스탯 합산 × 생산성 보정
- 팀원 체력 소모 (야근 시 추가 소모)
- 기술 부채 누적/감소 자동 적용
- 수습 직원 턴 카운트 증가
- 투자 심사 진행 카운트 증가

### Phase 4: 정산 (Settlement Phase)

| 주기 | 정산 항목 |
|------|-----------|
| 매 턴 | MAU 변동 계산, 서비스 평점 업데이트, 팀 케미 재계산 |
| 4턴마다 (월말) | 연봉 자동 차감, 운영비 차감, 복지비 차감, 마케팅비 차감, 서비스 매출 정산 |
| 12턴마다 (분기) | 세금 신고 이벤트 |
| 52턴마다 (연말) | 연말 정산, 성과 리뷰 이벤트 가능 |

### Phase 5: 결과 보고 (Report Phase)

- 턴 요약 대시보드 자동 표시
- 주요 수치 변동 하이라이트 (전 턴 대비)
- 예고 알림: 다음 턴 임박 이벤트 (수습 전환 D-2, 외주 납기 D-3, 연봉 지급일 등)
- 실패 조건 근접 경고 (자본 위기, 케미 위기 등)

## 3. 액션 슬롯

### 슬롯 종류

| 슬롯 | 횟수/턴 | 해당 액션 |
|------|---------|-----------|
| 메인 액션 | 3회 (리더십에 따라 최대 5회) | 채용, 해고, 외주 계약, 투자 신청, 리팩토링 착수, 팀 분리, 교육/컨퍼런스 |
| 자유 액션 | 무제한 | 복지 설정, 마케팅 예산, 대시보드, 업무 배분, 연봉 조정 |
| 긴급 액션 | 1회 | 번아웃 대응, 장애 대응, 보안 사고 대응 |

### 리더십에 따른 메인 액션 확장

| 리더십 | 메인 액션 |
|--------|-----------|
| 1~5 | 3회 |
| 6~7 | 4회 |
| 8~10 | 5회 |

## 4. 난이도 설정

| 난이도 | 초기 자본 | 팀 구성 | 이벤트 빈도 | 이력서 풀 | 턴 되돌리기 |
|--------|-----------|---------|-------------|-----------|-------------|
| 쉬움 | 5,000만 | 개발자 2명 | 낮음 | 중급 위주 | 가능 |
| 보통 | 2,000만 | 혼자 시작 | 표준 | 하~중급 혼합 | 가능 |
| 어려움 | 500만 | 혼자 시작 | 높음 | 하급 위주 | 불가 |
| 커스텀 | 직접 입력 | 직접 선택 | 직접 설정 | — | 선택 |

## 5. 회사 카테고리 선택

게임 시작 시 회사 카테고리를 선택한다. 선택한 카테고리는 외주 풀, 자체 서비스, 이벤트 구성에 영향을 준다.

상세 목록은 [회사](../game-domain/company.md) 참조.
