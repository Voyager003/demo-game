# 게임 진행 (Game Process)

## 1. 턴 구조

| 단위 | 환산 | 비고 |
|------|------|------|
| 1턴 | 1주일 | 기본 시간 단위 |
| 4턴 | 1개월 | 연봉 지급 주기 |
| 12턴 | 1분기 | 세금 신고 주기 |
| 52턴 | 1년 | 연말 정산 주기 |

---

## 2. 턴 내 페이즈 순서

매 턴은 아래 5개 페이즈를 순서대로 진행한다.

### Phase 1: 이벤트 발생 (Event Phase)

- 랜덤 이벤트 판정
- 외부 환경 이벤트 체크 (시장 트렌드, 법규제 변경)
- 히든 특성 발현 판정 (매 4턴마다 실행)
- 긴급 이벤트 발생 시 → 즉시 대응 여부 선택 (피로도 소모)
- 이벤트가 없으면 이 페이즈는 자동 스킵

### Phase 2: 의사결정 (Decision Phase)

- **행동 피로도(Fatigue)** 게이지 내에서 자유롭게 행동을 선택하여 실행
- 각 행동은 피로도를 소모하며, 피로도가 0이 되면 더 이상 행동 불가
- 행동마다 **쿨타임**이 있어, 피로도가 남아도 쿨타임 중인 행동은 실행 불가
- 피로도 0인 행동(대시보드 열람 등)은 제한 없이 실행 가능

### Phase 3: 실행/진행 (Execution Phase)

> 자동 처리 (플레이어 개입 없음)

- 진행 중인 프로젝트 진척도 계산: 투입 인력 스탯 합산 × 생산성 보정
- 팀원 체력 소모 (야근 시 추가 소모)
- 기술 부채 누적/감소 자동 적용
- 수습 직원 턴 카운트 증가
- 투자 심사 진행 카운트 증가
- **모든 행동의 쿨타임 1턴 감소**

### Phase 4: 정산 (Settlement Phase)

| 주기 | 정산 항목 |
|------|-----------|
| 매 턴 | MAU 변동 계산, 서비스 평점 업데이트, 팀 케미 재계산 |
| 4턴마다 (월말) | 연봉 자동 차감, 운영비 차감, 복지비 차감, 마케팅비 차감, 서비스 매출 정산 |
| 12턴마다 (분기) | 세금 신고 이벤트 |
| 52턴마다 (연말) | 연말 정산, 성과 리뷰 이벤트 가능 |

### Phase 5: 결과 보고 (Report Phase)

- 턴 요약 대시보드 자동 표시
- 주요 수치 변동 하이라이트 (전 턴 대비)
- **잔여 피로도 표시** (사용한 피로도 / 최대 피로도)
- **쿨타임 현황 표시** (다음 턴 사용 가능한 행동 목록)
- 예고 알림: 다음 턴 임박 이벤트 (수습 전환 D-2, 외주 납기 D-3, 연봉 지급일 등)
- 실패 조건 근접 경고 (자본 위기, 케미 위기 등)

## 3. 행동 피로도 시스템 (Fatigue System)

### 개요

대표(CEO)는 매 턴 **행동 피로도(Fatigue)** 게이지를 보유한다. 모든 행동은 이 피로도를 소모하며, 피로도가 0이 되면 해당 턴에서 더 이상 행동할 수 없다. 피로도는 **매 턴 시작 시 최대치로 회복**된다.

### 피로도 최대치

피로도 최대치는 대표의 **리더십(Leadership)** 스탯에 의해 결정된다.

| 리더십 | 최대 피로도 |
|--------|-----------|
| 1 | 6 |
| 2 | 7 |
| 3 | 8 |
| 4 | 9 |
| 5 | 10 |
| 6 | 12 |
| 7 | 14 |
| 8 | 16 |
| 9 | 18 |
| 10 | 20 |

> 리더십이 높을수록 한 턴에 더 많은 행동을 수행할 수 있다.

### 행동별 피로도 소모 & 쿨타임

모든 행동은 **피로도 소모량**과 **쿨타임(턴)**을 가진다. 쿨타임이 0인 행동은 매 턴 실행 가능하다.

#### 경영 행동

| 행동 | 피로도 | 쿨타임 | 설명 |
|------|--------|--------|------|
| 채용 공고 게시 | 3 | 2턴 | 이력서 풀 생성, 다음 턴부터 면접 가능 |
| 면접 및 채용 확정 | 2 | 0 | 이력서 풀에서 인재 선택 |
| 해고 | 2 | 1턴 | 직원 해고 처리 |
| 연봉 조정 | 1 | 4턴 | 특정 직원 연봉 변경 |
| 팀 분리/재편 | 3 | 8턴 | 조직 구조 변경 |
| 팀장 임명 | 2 | 4턴 | 팀 리더 지정 |

#### 프로젝트 행동

| 행동 | 피로도 | 쿨타임 | 설명 |
|------|--------|--------|------|
| 외주 계약 체결 | 3 | 1턴 | 새 외주 프로젝트 수주 |
| 업무 배분 변경 | 1 | 0 | 직원의 프로젝트 투입 비율 조정 |
| 리팩토링 착수 | 3 | 12턴 | 기술 부채 해소 프로젝트 시작 |
| 야근 지시 | 2 | 1턴 | 특정 팀/프로젝트에 야근 투입 |
| 코드리뷰 도입/해제 | 1 | 4턴 | 코드리뷰 프로세스 전환 |

#### 재무/투자 행동

| 행동 | 피로도 | 쿨타임 | 설명 |
|------|--------|--------|------|
| 투자 신청 | 4 | 8턴 | 투자 유치 프로세스 시작 |
| 대출 신청 | 2 | 4턴 | 단기 대출 실행 |
| 마케팅 예산 조정 | 1 | 0 | 마케팅 채널별 예산 변경 |
| 복지 설정 변경 | 1 | 0 | 복지 항목 추가/제거 |

#### 대표 성장 행동

| 행동 | 피로도 | 쿨타임 | 설명 |
|------|--------|--------|------|
| 외부 교육 수강 | 3 | 4턴 | 특정 스탯 +1 성장 |
| 컨퍼런스 참석 | 2 | 4턴 | 랜덤 스탯 성장 + 명성 +3 |
| 네트워킹 미팅 | 2 | 2턴 | 이력서 풀 품질↑ or 투자사 접촉 |

#### 위기 대응 행동

| 행동 | 피로도 | 쿨타임 | 설명 |
|------|--------|--------|------|
| 긴급 장애 대응 | 3 | 0 | 서비스 장애 즉시 대응 |
| 번아웃 직원 케어 | 2 | 0 | 번아웃 선언 직원 휴가/상담 |
| 갈등 중재 | 2 | 1턴 | 팀원 간 갈등 중재 |
| 위기 회의 소집 | 4 | 2턴 | 중대 위기 시 전사 대응 (위기 대응력 5+: 추가 옵션) |

#### 무료 행동 (피로도 0)

| 행동 | 피로도 | 쿨타임 | 설명 |
|------|--------|--------|------|
| 대시보드 열람 | 0 | 0 | 재무/팀/서비스 현황 확인 |
| 이벤트 로그 확인 | 0 | 0 | 최근 이벤트 이력 열람 |
| 직원 정보 열람 | 0 | 0 | 개별 직원 스탯/특성 확인 |
| 턴 종료 | 0 | 0 | 남은 피로도를 포기하고 다음 턴 진행 |

### 피로도 운영 전략

- **피로도를 아끼는 플레이**: 저비용 행동 위주로 안정적 운영
- **피로도를 몰아쓰는 플레이**: 한 턴에 대형 의사결정을 집중, 다음 턴은 쿨타임 대기
- **쿨타임 관리**: 채용(2턴)과 외주 계약(1턴)을 교대로 실행하면 매 턴 생산적 운영 가능
- **위기 대비**: 피로도 2~3을 항상 남겨두면 긴급 이벤트에 즉시 대응 가능

### 리더십과 피로도의 관계 (결정론적 레이어)

리더십 스탯이 높을수록:
- 최대 피로도 증가 → 한 턴에 더 많은 행동 가능
- 팀 케미 안정화 보정 유지 (기존과 동일)

> 리더십 1(피로도 6)으로는 채용(3) + 외주 계약(3) = 한 턴에 딱 2개 대형 행동만 가능.
> 리더십 10(피로도 20)이면 채용(3) + 외주 계약(3) + 투자 신청(4) + 교육(3) + 기타(7) = 다양한 조합 가능.
