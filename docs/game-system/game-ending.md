# 엔딩 시스템 (Ending System)

## 1. 게임 목표 구조 (레이어드 목표)

게임 목표는 4개의 레이어로 구성되며, 플레이어가 자연스럽게 단기→중기→장기 목표를 쌓아가도록 유도한다.

```
단기 목표 (매 4~8턴)   → 외주 납품 성공, 연봉 지급 유지
중기 목표 (매 20~40턴) → 시리즈 업그레이드, MAU 달성
장기 목표 (50~100턴)   → 엔딩 조건 충족
숨겨진 목표            → 히든 엔딩 트리거
```

- 단기 목표는 현금 흐름 유지에 집중하며, 실패 시 즉각적인 페널티가 발생한다.
- 중기 목표는 회사의 성장 방향을 결정짓는 분기점 역할을 한다.
- 장기 목표 달성 여부에 따라 최종 엔딩 등급이 결정된다.
- 숨겨진 목표는 특수한 플레이 패턴을 감지하여 히든 엔딩으로 분기한다.

---

## 2. 파산 위기 및 유예 시스템

자본이 0원 이하로 떨어지면 즉시 게임 오버가 아닌 **위기 상태**에 진입한다. 플레이어에게 회사를 수습할 기회가 주어진다.

### 위기 상태 진입

```
자본 0원 이하 → "위기 상태" 진입
  ↓
기본 유예 기간: 4턴
  예상 수입(미수금 잔금, 진행 중 외주 선금 등)이 있는 경우 → +4턴 (최대 8턴)
  ↓
유예 기간 중 가능한 행동:
  - 긴급 대출 신청
  - 투자 유치 시도
  - 직원 연봉 동결/감액
  - 자산 매각 (사무실 축소 등)
  ↓
유예 기간 만료 시 자본 미회복 → Game Over (F등급)
```

### 위기 상태 시 직원 행동

위기 상태에 진입하면 직원들은 **충성도와 특성**에 따라 다르게 반응한다. 무급으로 잔류하는 직원은 생산성이 50%로 감소한다.

| 충성도 (-1~5) | 행동 |
|---------------|------|
| **3~5** | 무급으로 최대 4턴 잔류. 이후에도 자본 미회복 시 퇴사. |
| **1~2** | 50% 확률로 잔류. 매 턴 재판정. |
| **0 이하** | 즉시 퇴사. |

| 특성 | 행동 |
|------|------|
| **배려형리더** | 무조건 끝까지 잔류 (유예 기간 전체) |
| **이직욕구자** | 위기 상태 진입 즉시 퇴사 |

### 즉시 실패 조건 (유예 없음)

아래 조건은 유예 없이 즉시 게임 오버가 발생한다.

| 조건 | 설명 |
|------|------|
| 소송 패소 + 배상금 미지불 | 강제 청산 |
| 보안 해킹 + 명성 10 이하 동시 | 서비스 강제 종료 |

- 소송 패소 후 배상금 지불 능력이 있으면 자본에서 차감되고 게임은 계속된다.
- 보안 해킹은 이벤트 시스템에서 발생하며, 명성이 충분하면 복구 가능하다.

## 3. 누적 실패 조건

단발성이 아닌, 일정 기간 지속되는 부정적 상태가 임계점을 넘으면 실패 루트에 진입한다.

| 조건 | 설명 |
|------|------|
| 팀 케미 0~10 6턴 연속 | 전원 퇴사 엔딩 |
| 개발자 전원 이탈 + 진행 중 외주 | 계약 파기 연쇄 → 부도 루트 |
| 명성 5 이하 4턴 유지 | 이력서 풀 고갈, 계약 불가 → 자연 소멸 |

- 누적 실패 조건은 경고 단계(임계점 직전)에서 알림이 표시된다.
- 팀 케미 저하에 의한 전원 퇴사는 F등급 엔딩으로 직행한다.
- 개발자 전원 이탈 시 외주 계약 파기 위약금이 자본에서 차감되며, 자본 부족 시 부도 처리된다.
- 명성 5 이하 상태에서는 채용 지원자 수가 0이 되고, 외주 계약 제안도 중단된다.

---

## 4. 멀티 엔딩 구조

엔딩은 S~F의 6개 등급으로 분류되며, 각 등급에 고유한 연출이 존재한다.

| 등급 | 엔딩명 | 조건 | 연출 |
|------|--------|------|------|
| S | 유니콘 달성 | 시리즈 C+ & MAU 100만+ & 명성 90+ | IPO 신문 기사 |
| A | 안정적 중견기업 | 시리즈 B & 흑자 전환 & 케미 70+ | 사옥 이전 컷씬 |
| B | 탄탄한 외주 강자 | 투자 없이 외주 수익 20턴+ 흑자 | 단골 클라이언트 리스트 |
| C | 생존 | 적자 없이 50턴 버팀 | 무난한 일상 엔딩 |
| D | 소프트 랜딩 | 자본 양수에서 자진 청산 | 팀원 행선지 표시 |
| F | 파산 | 자본 고갈 or 연쇄 이탈 | 잡플래닛 리뷰 스크롤 |

- 복수 조건을 동시에 충족하면 더 높은 등급의 엔딩이 우선 적용된다.
- D등급 소프트 랜딩은 플레이어가 자진 청산을 선택해야 발동되는 유일한 능동적 엔딩이다.
- F등급 파산 엔딩은 즉시 실패 또는 누적 실패 조건에 의해 자동 트리거된다.

---

## 5. 히든 엔딩

특수한 플레이 패턴을 충족하면 일반 엔딩 대신 히든 엔딩이 발동된다.

| 엔딩 | 조건 | 연출 |
|------|------|------|
| 창업 꿈나무의 복수 | 창업꿈나무 해고 후 경쟁사 성장, MAU 역전 | 경쟁 서비스 뉴스 기사 |
| 조용한 제국 | 마케팅비 0원 유지하며 시리즈 A 달성 | 바이럴 성장 히스토리 |
| 재기의 불꽃 (Phoenix Restart) | 파산 Game Over 시, 유예 기간 끝까지 잔류한 직원 1명 이상 | "N명의 동료가 끝까지 함께했다" 메시지 |

### 재기의 불꽃 상세

파산으로 게임이 종료되더라도, 끝까지 함께한 직원이 있다면 **"재기 모드"**로 새 게임을 시작할 수 있다.

| 항목 | 재기 모드 조건 |
|------|--------------|
| **초기 자본** | 500만원 (기본 2,000만보다 낮음) |
| **잔류 직원** | 이전 게임에서 끝까지 잔류한 직원이 이미 채용된 상태로 시작 |
| **잔류 직원 충성도** | 최대치(5)로 고정 |
| **명성** | 5 (파산 이력 반영) |
| **도메인** | 이전 게임과 동일 |

> 재기 모드는 자본과 명성이 열악하지만, 충성도 최대인 검증된 팀원과 함께 시작하는 독특한 플레이 경험을 제공한다.

- 히든 엔딩은 일반 엔딩보다 높은 우선순위를 갖는다.
- 조건 충족 즉시 트리거되며, 해당 턴의 Phase 4 정산 이후 판정된다.
- 히든 엔딩 달성 시 별도의 업적 시스템에 기록된다.

---

## 6. 엔딩 판정 시점

- 매 턴 Phase 4 (정산) 이후 실패 조건 체크
- 장기 목표 달성은 특정 턴에 도달하거나 조건 충족 시 엔딩 분기
- 히든 엔딩은 조건 충족 즉시 트리거 (일반 엔딩보다 우선)

판정 순서:

```
1. 즉시 실패 조건 체크 → 해당 시 Game Over
2. 누적 실패 조건 체크 → 해당 시 F등급 엔딩
3. 히든 엔딩 조건 체크 → 해당 시 히든 엔딩 트리거
4. 장기 목표 달성 체크 → 해당 시 S~D등급 엔딩 분기
5. 조건 미충족 시 → 다음 턴 진행
```
